# Devcontainer

Development containers let you run this project in a reproducible Docker-based environment.

- Open the repository in VS Code.
- If the Dev Containers extension is installed, reopen in container when prompted.
- See [doc/devcontainers.md](https://github.com/kspaceKelvin/python-ismrmrd-server/blob/master/doc/devcontainers.md) for project-specific notes.

The devcontainer is also compatible with [GitHub Codespaces](https://github.com/features/codespaces). The repository configuration is in the [`.devcontainer/` folder](https://github.com/kspaceKelvin/python-ismrmrd-server/tree/master/.devcontainer). If the Dev Containers extension is installed in VS Code, reopening the repository in the container provides the configured project environment without installing dependencies on the host.
