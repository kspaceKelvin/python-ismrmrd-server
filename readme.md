# Python ISMRMRD Server

This repository is a reference implementation of the [ISMRM Raw Data (MRD) network streaming format](https://ismrmrd.readthedocs.io/en/latest/index.html).  It enables the integration of MR image reconstruction and analysis algorithms in a vendor neutral, cross-platform format that can be readily distributed through the use of container formats like Docker.

Documentation for this repository can be found at https://kspacekelvin.github.io/python-ismrmrd-server/
